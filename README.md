# ইসলাম শিখি

দৈনন্দিন ইবাদত, কুরআন, দোয়া, মাসআলা ও ব্যক্তিগত উন্নতির জন্য একটি অফলাইন-ফার্স্ট ইসলামিক Android অ্যাপ।

- **প্ল্যাটফর্ম:** Android 8.0 (API 26) বা তার ওপরে
- **প্রযুক্তি:** Kotlin, Jetpack Compose, Material 3, DataStore (পরে Room, WorkManager)
- **গোপনীয়তা:** সব ব্যক্তিগত তথ্য শুধু ডিভাইসে থাকে। অ্যাকাউন্ট, বিজ্ঞাপন বা সার্ভার নেই।

## সবচেয়ে সহজ উপায়: GitHub থেকে APK নামানো (Android Studio ছাড়া)

1. রিপোজিটরির **Actions** ট্যাবে যান।
2. বামে **Build Debug APK** চাপুন, তারপর সর্বশেষ রান খুলুন (সবুজ টিক থাকলে বিল্ড সফল)।
3. পাতার নিচে **Artifacts** অংশ থেকে `islam-shikhi-debug-apk` নামান। এটি একটি zip; খুললে `app-debug.apk` পাবেন।
4. APK ফোনে পাঠিয়ে ইনস্টল করুন (ফোনে "Unknown sources" থেকে ইনস্টলের অনুমতি দিতে হতে পারে)।
5. লাল ✗ দেখালে রানটি খুলে Error-এর লেখা কপি করে আমাকে পাঠান।

## Android Studio দিয়ে বিল্ড ও চালানো

1. **Android Studio** (সর্বশেষ স্থিতিশীল সংস্করণ) ইনস্টল করুন।
2. `File > Open` থেকে এই প্রজেক্ট ফোল্ডারটি খুলুন।
3. Gradle Sync শেষ হওয়া পর্যন্ত অপেক্ষা করুন। প্রথমবার ইন্টারনেট লাগবে।
   - `gradle-wrapper.jar` ফাইলটি এই রিপোজিটরিতে নেই। Android Studio নিজে Gradle ডাউনলোড করে নেবে।
4. ফোনে **Developer options > USB debugging** চালু করে ফোন কম্পিউটারে লাগান, অথবা Emulator বানান।
5. ওপরের সবুজ **Run ▶** বাটনে চাপুন।

### Debug APK বানানো
`Build > Build Bundle(s) / APK(s) > Build APK(s)`। শেষ হলে নিচে ডানে **locate** চাপলে `app/build/outputs/apk/debug/app-debug.apk` পাবেন। এটি ফোনে কপি করে ইনস্টল করুন (ফোনে "Unknown sources" থেকে ইনস্টলের অনুমতি দিতে হতে পারে)।
