# শিশুদের শিক্ষা, জরুরি গাইড, লাইব্রেরি ও বই

চারটি ফাইলের কাঠামো একই। শুধু ফাইল ভিন্ন:

| অ্যাপের পাতা | ফাইল |
|---|---|
| শিশুদের শিক্ষা | `kids.json` |
| জরুরি গাইড | `emergency.json` |
| ইসলামিক লাইব্রেরি | `library.json` |
| বই ও লেখক | `books.json` |

ফোল্ডার: `app/src/main/assets/content/`

## কাঠামো

```
{
 "schemaVersion": 1,
 "categories": [ { "id": "basics", "titleBn": "বিভাগের নাম" } ],
 "items": [
  {
   "id": "kid_pillars",
   "category": "basics",
   "titleBn": "শিরোনাম",
   "summaryBn": "এক-দুই লাইনের সারসংক্ষেপ",
   "sections": [
    { "titleBn": "অংশের নাম", "bodyBn": "লেখা...", "sourceRef": "উৎস" }
   ],
   "audience": ["ALL"],
   "minAgeGroup": null,
   "verificationStatus": "SOURCE_CHECKED"
  }
 ]
}
```

- `categories` অ্যাপের পাতায় শিরোনাম হিসেবে দেখায়।
- `items`: প্রতিটি আইটেম একটা কার্ড।
- `sections`: কার্ডের ভেতরের অংশ।

## লেখা ঠিক করা

`titleBn`, `summaryBn`, `bodyBn`-এর বাংলা লেখা সরাসরি বদলান। `id`, `category`, `verificationStatus` বদলাবেন না।

## নতুন আইটেম যোগ

1. শেষ আইটেমের `}`-এর পরে কমা দিন।
2. একটা পুরনো আইটেম (`{` থেকে `}`) কপি করে পেস্ট করুন।
3. `id` নতুন ও অনন্য দিন।
4. লেখা বদলান। প্রতিটি `section`-এ `sourceRef` দিন। কমপক্ষে একটি অংশে উৎস থাকতেই হবে।
5. `"category"` আগে থেকে থাকা বিভাগের `id`-এর সাথে হুবহু মিলতে হবে।
6. `"verificationStatus"` রাখুন `"DRAFT"` (মানে আলেমের যাচাই হয়নি)। `SCHOLAR_REVIEWED` লিখবেন না।

## বই ও লেখক (`books.json`)

এখানে **লেখক = বিভাগ (`categories`)**, **বই = আইটেম (`items`)**, **অধ্যায় = অংশ (`sections`)**।

### নতুন লেখক যোগ

`"categories": [` এর ভেতরে যোগ করুন (আগে থাকলে কমা দিয়ে):

```
{ "id": "author_rahim", "titleBn": "লেখকের নাম" }
```

### নতুন বই যোগ

`"items": [` এর ভেতরে:

```
{
 "id": "book_rahim_1",
 "category": "author_rahim",
 "titleBn": "বইয়ের নাম",
 "summaryBn": "বইয়ের সংক্ষিপ্ত পরিচয়",
 "sections": [
  { "titleBn": "প্রথম অধ্যায়", "bodyBn": "অধ্যায়ের লেখা...", "sourceRef": "বই, অধ্যায় ১" }
 ],
 "audience": ["ALL"],
 "minAgeGroup": null,
 "verificationStatus": "DRAFT"
}
```

- `category` লেখকের `id`-র সাথে মিলতে হবে।
- প্রথম বই যোগ হলে অ্যাপের সহকারী ট্যাবে "বই ও লেখক" কার্ড নিজে থেকে দেখাবে।
- **কপিরাইট:** লেখক বা প্রকাশকের লিখিত অনুমতি, পাবলিক ডোমেইন বা নিজের লেখা ছাড়া কোনো বই যোগ করবেন না।
