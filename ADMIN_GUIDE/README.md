# এডমিন গাইড — "ইসলাম শিখি" অ্যাপের লেখা বদলানো

এই ফোল্ডারটি শুধু এডমিনদের জন্য। এটা অ্যাপের ভেতরে নেই, ব্যবহারকারী এটা দেখে না।
কোডিং জানা লাগবে না। শুধু ব্রাউজারে GitHub খুলে ধাপগুলো মেনে চলুন।

## কোন পাতার লেখা কোন ফাইলে

| অ্যাপের পাতা | ফাইল (`app/src/main/assets/content/` ফোল্ডারে) | গাইড |
|---|---|---|
| ইসলামি জ্ঞান (প্রবন্ধ) | `ilm.json` | [02_ইসলামি-জ্ঞান.md](02_ইসলামি-জ্ঞান.md) |
| মাসআলা-মাসায়েল | `masail.json` | [03_মাসআলা.md](03_মাসআলা.md) |
| দোয়া | `duas.json` | [04_দোয়া.md](04_দোয়া.md) |
| ইসলামিক কুইজ | `quiz.json` | [05_কুইজ.md](05_কুইজ.md) |
| শিশুদের শিক্ষা, জরুরি গাইড, ইসলামিক লাইব্রেরি, বই ও লেখক | `kids.json`, `emergency.json`, `library.json`, `books.json` | [06_শিশু-জরুরি-লাইব্রেরি-বই.md](06_শিশু-জরুরি-লাইব্রেরি-বই.md) |
| হোমের ঘোষণা ও নতুন সংস্করণের খবর | GitHub-এ নয়, Firebase-এ | [07_ঘোষণা-ও-খবর.md](07_ঘোষণা-ও-খবর.md) |

**যা এই পথে বদলানো যায় না:** কুরআনের আরবি ও অনুবাদ, নামাজের সময়ের হিসাব, অ্যাপের বাটন বা ডিজাইন। এগুলোর জন্য অ্যাপের নতুন সংস্করণ লাগে। ডেভেলপারকে জানান।

## সবার আগে পড়ুন

## ডেভেলপারের জন্য নোট

`ilm.json`, `masail.json`, `duas.json` আসলে `tools/` ফোল্ডারের স্ক্রিপ্ট (`build_ilm.py`, `build_duas.py` ইত্যাদি) দিয়ে বানানো। এডমিন সরাসরি এগুলো বদলালে, পরে ডেভেলপার ওই স্ক্রিপ্ট আবার চালালে বদলগুলো মুছে যাবে। তাই স্ক্রিপ্ট চালানোর আগে `tools/content/` ফাইলে একই বদল তুলে নিন।
