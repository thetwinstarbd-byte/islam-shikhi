# সমস্যা হলে

## Actions ট্যাবে লাল ক্রস দেখাচ্ছে

1. রিপোজিটরির **Actions** ট্যাব → লাল **Publish Content** লাইন চাপুন।
2. **publish** নামের কাজ চাপুন।
3. লাল অংশে ইংরেজি বা বাংলায় কারণ লেখা থাকে। সাধারণ কারণগুলো:

| বার্তায় যা লেখা | মানে ও সমাধান |
|---|---|
| `JSONDecodeError`, `Expecting ',' delimiter`, `Expecting property name` | কমা, `"`, `{ }` বা `[ ]` মুছে গেছে বা বেশি হয়েছে। বদলানো জায়গাটা আবার দেখুন, নয়তো সর্বশেষ বদলানো Revert করুন। |
| `sourceRef নেই` / `সূত্র ফাঁকা` | কোনো আইটেম বা কুইজে উৎস লেখা হয়নি। উৎস যোগ করুন। |
| `অবৈধ verificationStatus` | `verificationStatus`-এ শুধু `DRAFT` বা `SOURCE_CHECKED` রাখুন। |
| `SCHOLAR_REVIEWED` | আলেমের পর্যালোচনা ছাড়া এটা লেখা যাবে না। `SOURCE_CHECKED` বা `DRAFT` রাখুন। |
| `আইডি ডুপ্লিকেট` | দুটো এন্ট্রির `id` এক। একটা বদলান। |
| `অজানা বিভাগ` | `category`-র মান `categories`-এর কোনো `id`-র সাথে মেলে না। |

4. ঠিক করে আবার Commit করলে নিজে আবার যাচাই হবে।

**লাল ক্রস মানে ব্যবহারকারীর কোনো ক্ষতি হয়নি।** ভুল লেখা অ্যাপে যায়নি।

## ভুল লেখা প্রকাশ হয়ে গেছে (সবুজ টিক কিন্তু লেখাটা ভুল)

1. দ্রুত ঠিক লেখা বসিয়ে আবার Commit করুন।
2. অথবা ফাইলের **History** থেকে ভুল Commit **Revert** করুন।
3. ব্যবহারকারীর অ্যাপ পরের বার নেটে খুললে ঠিক লেখা পাবে।

## ব্যবহারকারী নতুন লেখা পাচ্ছে না

- তাদের ফোনে নেট আছে কি না দেখতে বলুন, এবং অ্যাপ বন্ধ করে আবার খুলতে বলুন।
- অ্যাপ প্রতিবার খোলার সময় (১০ মিনিটের ব্যবধানে) নতুন লেখা খোঁজে।
- অ্যাপের নতুন সংস্করণ ছাড়া পুরনো সংস্করণের কিছু ব্যবহারকারী নতুন ধরনের ফাইল (যেমন `books.json`) পাবে না।

## ডেভেলপারকে কী জানাবেন

- কোন ফাইল ও কোন আইটেমে কী বদলাতে চেয়েছিলেন
- Actions-এর লাল অংশের লেখা (কপি করে বা স্ক্রিনশট)
- কখন বদলেছিলেন
