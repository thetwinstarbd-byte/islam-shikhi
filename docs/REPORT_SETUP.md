# "ভুল জানান" চালু করার নির্দেশিকা (একবারের কাজ, ৫ মিনিট, বিনামূল্যে)

ব্যবহারকারী অ্যাপে লিখে ও ফাইল দিয়ে "পাঠান" চাপলে লেখাটি সরাসরি **আপনার জিমেইলে** আসবে। কারও কিছু করতে হবে না, কার্ডও লাগে না।
এটি Google Apps Script দিয়ে চলে (আপনার Google অ্যাকাউন্টেই)।

## ধাপ
1. https://script.google.com খুলুন (আপনার জিমেইল দিয়ে) → **New project**।
2. কোড-ঘরের সব লেখা মুছে `tools/report_mail.gs` ফাইলের পুরো লেখা বসান।
3. ওপরের `TOKEN`-এর জায়গায় নিজের একটি লম্বা গোপন কোড লিখুন (যেমন ২০টি এলোমেলো অক্ষর)। এটি মনে রাখুন।
4. ডানে ওপরে **Deploy → New deployment → Select type: Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - **Deploy** চাপুন, Google যে অনুমতি চায় (ইমেইল পাঠানো) তা দিন ("Advanced → Go to ... (unsafe)" এলে সেটিও ঠিক আছে, এটি আপনার নিজের স্ক্রিপ্ট)।
5. যে **Web app URL** পাবেন (`https://script.google.com/macros/s/.../exec`) সেটি কপি করুন।
6. GitHub রিপোজিটরিতে যান: **Settings → Secrets and variables → Actions → New repository secret**:
   - `REPORT_URL` = ওই URL
   - `REPORT_TOKEN` = ধাপ ৩-এর গোপন কোড
7. Actions ট্যাব থেকে একটি নতুন বিল্ড চালান (বা নতুন কিছু push করুন)। নতুন APK-তে "ভুল জানান" চালু থাকবে।

## জেনে রাখুন
- দিনে সর্বোচ্চ ৬০টি বার্তা নেওয়া হয় (স্প্যাম ঠেকাতে); Gmail-এর নিজস্ব দৈনিক সীমাও আছে।
- ফাইল সর্বোচ্চ ৪ MB। বেশি বড় হলে অ্যাপ নিষেধ করে।
- URL ও TOKEN রিপোজিটরির কোডে লেখা নেই (রিপোজিটরি পাবলিক); শুধু GitHub Secrets-এ থাকে। তবু APK-র ভেতর থেকে কেউ বের করতে পারে, তাই TOKEN বদলাতে চাইলে স্ক্রিপ্টে ও Secret-এ একসাথে বদলান। স্প্যাম এলে নতুন Deployment করে URL বদলে দিন।
- ইন্টারনেট না থাকলে অ্যাপ বার্তা ফোনে রেখে পরের বার খোলার সময় নিজে পাঠায়।
- গোপনীয়তা: বার্তা, ফাইল, অ্যাপ-সংস্করণ ও ফোনের মডেল ছাড়া কিছু যায় না; আর ব্যবহারকারী নিজে "পাঠান" না চাপলে কিছুই যায় না।
